# Rejected: manananggal, 2026-08-29

Generated, paid for, and not shipped. Two reasons, either of which is enough:

1. **Bare chested.** Google Play prohibits nudity. This would fail content
   rating or get the listing pulled.
2. **Wrong creature.** It is a generic horned winged demon. A manananggal is a
   woman who SEVERS AT THE WAIST; the upper half flies on bat wings trailing its
   entrails, and the lower half stands where it was left. Nothing about the
   model says any of that.

Kept rather than deleted so the 35 credits are not spent again by accident, and
so the wings are available if a future version reuses them.
